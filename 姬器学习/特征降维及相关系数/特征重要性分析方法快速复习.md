# 特征重要性分析方法快速复习

## 1. 先分清几个概念

特征降维/特征筛选的目标是: 用更少、更有效的特征训练模型, 减少噪声、降低过拟合风险、提高训练速度。

常见方法可以分成三类:

- 特征选择: 从原始特征里挑一部分留下, 例如低方差法、相关系数法、互信息、Permutation Importance。
- 特征变换: 把原始特征重新组合成新特征, 例如 PCA。
- 模型解释: 训练模型后解释哪些特征重要, 例如随机森林重要性、SHAP。

一句话记忆:

- 低方差法: 这列几乎没变化, 先删。
- 相关系数法: 这列和目标没关系, 或者和别的列太重复, 考虑删。
- PCA: 这些列信息重叠, 合成几个新列。
- 互信息: 不只看直线, 看知道 X 后能减少多少对 Y 的不确定性。
- Permutation: 打乱某列后模型变差多少, 变差越多越重要。
- SHAP: 解释每个样本里各个特征把预测值往哪个方向推。

## 2. 低方差法 VarianceThreshold

适用场景:

- 高维稀疏数据的初筛。
- 文本分类/垃圾邮件分类: 词袋特征可能有几万列, 很多词几乎从不出现。
- 基因表达数据: 有些基因在所有样本里表达量几乎不变。
- 用户画像/推荐系统: 某些0/1字段几乎全是0或全是1。

核心原理:

```text
Var(X) = sum((xi - mean(X)) ** 2) / n
```

方差越小, 说明这个特征在不同样本之间越没变化, 区分能力可能越弱。

二值特征中, 如果1出现比例是 p:

```text
Var(X) = p * (1 - p)
```

超参:

```python
VarianceThreshold(threshold=0)
```

- `threshold=0`: 只删除完全不变的列。
- `threshold=0.01 * 0.99`: 可用于删除出现比例低于1%或高于99%的二值特征。
- `threshold=0.05 * 0.95`: 可用于删除出现比例低于5%或高于95%的二值特征。

注意:

- 它不看标签 y, 所以只能做粗筛。
- 方差小不一定绝对没用, 方差大也不一定对预测有用。

## 3. 相关系数法 Pearson / Spearman

适用场景:

- 快速判断数值特征和目标之间是否有关。
- 快速判断两个特征是否高度重复。
- 经典数据集: Iris、Wine、Diabetes、California Housing。

Pearson 皮尔逊相关系数:

```text
r = Cov(X, Y) / (std(X) * std(Y))
```

适合判断线性关系, 例如房屋面积越大, 房价整体越高。

Spearman 斯皮尔曼相关系数:

```text
rho = Pearson(rank(X), rank(Y))
```

适合判断单调关系或排名关系, 对异常值相对更稳。

取值理解:

- 接近 1: 强正相关。
- 接近 -1: 强负相关。
- 接近 0: 简单相关性弱。

阈值经验:

- `|r| < 0.1`: 很弱。
- `0.3 <= |r| < 0.5`: 中等。
- `|r| >= 0.8`: 很强, 特征之间可能重复。

注意:

- Pearson主要看直线关系。
- Spearman主要看单调关系。
- 对 `y = x ** 2` 这种抛物线关系, 它们都可能接近0。
- 对组合关系也容易失效, 例如 XOR 问题。

## 4. PCA 主成分分析

适用场景:

- 特征之间有明显冗余。
- 想把高维数据压缩成低维。
- 想把数据压到2维或3维做可视化。
- 经典数据集: Iris、Digits、MNIST、人脸图像、Wine。

核心原理:

PCA寻找数据变化最大的方向。第1主成分解释最多方差信息, 第2主成分解释次多信息, 以此类推。

简化步骤:

```text
1. 中心化: X_centered = X - mean(X)
2. 协方差矩阵: Cov = X_centered.T @ X_centered / n
3. 特征分解: Cov @ v = lambda @ v
```

- `v`: 主成分方向。
- `lambda`: 该方向上的方差信息量。

超参:

```python
PCA(n_components=2)
PCA(n_components=0.95)
```

- 整数: 保留几个主成分。
- 小数: 保留多少累计方差信息。

常用选择:

- 可视化: `2` 或 `3`。
- 建模压缩: `0.90`、`0.95`、`0.99`, 再用验证集比较模型效果。

注意:

- PCA生成的是新特征, 不再保留原始特征含义。
- PCA对量纲敏感, 通常先做 `StandardScaler`。

## 5. 随机森林/树模型特征重要性

适用场景:

- 有非线性关系。
- 有组合关系。
- 想快速知道模型主要依赖哪些特征。

经典例子:

- XOR: 单看 `x1` 或 `x2` 都不明显, 组合起来才有规律。
- 房价: 面积、位置、房龄可能通过复杂组合影响房价。
- 用户购买预测: 年龄、收入、城市、浏览行为之间可能存在条件组合。

注意:

- 随机森林给的是 feature importance, 不是相关系数。
- 相关系数问的是两个变量有没有简单统计关系。
- 特征重要性问的是模型预测时有没有用到这个特征。

## 6. Permutation Importance

适用场景:

- 已经训练好了模型, 想判断某个特征对模型效果的贡献。
- 希望用更直观的方式解释特征重要性。

核心原理:

1. 先记录模型在验证集上的分数。
2. 随机打乱某个特征列。
3. 再看模型分数下降多少。
4. 下降越多, 说明该特征越重要。

优点:

- 思路直观。
- 不限模型类型, 线性模型、树模型、神经网络都可以用。

注意:

- 应该在验证集/测试集上做, 不建议只在训练集上看。
- 如果两个特征高度相关, 打乱其中一个时, 另一个可能还能顶上, 重要性会被低估。
- 如果怀疑组合关系, 可以尝试同时打乱一组特征。

## 7. SHAP

适用场景:

- 想解释模型对单个样本为什么这么预测。
- 想看全局特征重要性。
- 想分析特征影响方向, 例如特征值越大是推高预测还是拉低预测。
- 想进一步研究特征交互。

核心原理:

SHAP来自博弈论思想, 可以粗略理解为:

```text
把一次预测结果分摊给每个特征, 看每个特征贡献了多少。
```

解释方式:

- SHAP值 > 0: 这个特征把预测往更大的方向推。
- SHAP值 < 0: 这个特征把预测往更小的方向推。
- 绝对值越大: 对该样本预测影响越大。

注意:

- SHAP需要额外安装 `shap` 包。
- 对树模型解释效果常用且成熟。
- 初学阶段先会看全局重要性和单样本解释即可。

## 8. 互信息 Mutual Information

适用场景:

- 怀疑存在非线性关系。
- 不确定特征和目标之间是什么形状的关系。
- 希望做比相关系数更灵活的特征筛选。

核心原理:

互信息衡量:

```text
知道 X 以后, 能减少多少对 Y 的不确定性。
```

sklearn 中常用:

```python
from sklearn.feature_selection import mutual_info_classif
from sklearn.feature_selection import mutual_info_regression
```

- 分类任务: `mutual_info_classif`
- 回归任务: `mutual_info_regression`

注意:

- 互信息能发现非线性关系, 但不直接告诉你关系形状。
- 分数不如相关系数那样直观。
- 建议配合散点图或模型解释一起看。

## 9. GAM 和样条模型

适用场景:

- 你怀疑特征和目标之间是非线性关系。
- 你又希望模型有较强解释性。
- 比如年龄、收入、剂量、温度等变量对结果的影响不是简单直线。

GAM 的思想:

```text
y = f1(x1) + f2(x2) + f3(x3) + ...
```

每个 `fi` 可以是一条平滑曲线。

样条模型 Spline:

可以把一条复杂曲线拆成多个区间, 每个区间用简单函数拟合, 再平滑连接起来。

适合看:

- U型关系。
- 倒U型关系。
- S型关系。
- 分段变化关系。

注意:

- GAM/样条比普通线性模型更灵活, 但比随机森林、XGBoost更容易解释。
- 初学阶段可以先知道它们是“解释非线性曲线”的工具。

## 10. 快速选择指南

| 问题 | 优先方法 |
| --- | --- |
| 特征几乎没变化 | 低方差法 |
| 线性关系 | Pearson |
| 单调但不一定线性 | Spearman |
| 抛物线/U型/复杂非线性 | 散点图、互信息、树模型、多项式特征 |
| 多个特征组合后才有用 | 树模型、Permutation、SHAP、交叉特征 |
| 特征很多且稀疏 | 低方差法、互信息、线性模型筛选 |
| 特征之间冗余强 | 相关系数矩阵、PCA |
| 想解释单个预测 | SHAP |
| 想解释打乱某列影响多大 | Permutation Importance |

## 11. 实战推荐流程

1. 先做基础探索:
   - 看缺失值。
   - 看特征分布。
   - 数值特征画散点图/相关系数矩阵。

2. 特征很多时:
   - 先用低方差法删掉几乎不变的列。
   - 再用互信息或模型重要性做进一步筛选。

3. 怀疑特征重复时:
   - 看相关系数矩阵。
   - 对高度相关的特征, 保留更稳定、更好解释、和目标关系更强的那个。

4. 怀疑非线性或组合关系时:
   - 画图。
   - 尝试多项式特征。
   - 使用随机森林/XGBoost等树模型。
   - 用 Permutation 或 SHAP 解释。

5. 特征之间冗余明显且不太要求解释原始含义时:
   - 尝试 PCA。
   - 用验证集比较降维前后的模型效果。
