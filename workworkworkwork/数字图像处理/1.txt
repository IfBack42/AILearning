这一章是所有数字图像处理的“地基”，回答了最根本的问题：一张物理世界的照片，到底是怎么变成电脑里那个数字矩阵的？
1.1 取样与量化——数字化的两大步

把一张模拟图像（比如胶片照片）变成数字图像，需要两个步骤：
① 取样（Sampling）

    做什么：把连续的空间坐标离散化。也就是在图像平面上，按一定间隔“打点”。

    决定什么：图像的分辨率（宽 × 高），比如 1920×1080。

    通俗理解：像用网格覆盖照片，每个格子只取一个颜色值。格子越密，分辨率越高，细节保留越多。

② 量化（Quantization）

    做什么：把连续的亮度/颜色值离散化。每个取样点的亮度，用一个整数来表示。

    决定什么：图像的位深（bit depth）。8位量化 → 0~255灰度；24位彩色 → RGB各8位。

    通俗理解：把连续的光强刻度“四舍五入”到最接近的整数档位。档位越多（位数越高），灰度层次越细腻。

一句话：取样决定“有多少个点”，量化决定“每个点能表示多精细的颜色”。
1.2 三基色原理

    人的视网膜上有三种感色细胞，分别对红（R）、绿（G）、蓝（B）敏感。

    加法混色：R+G+B = 白光。显示器、数码相机都基于此，每个像素由RGB三个分量组成。

    工程意义：理解为什么彩色图像是三个通道；为什么颜色空间转换（RGB ↔ HSV）在图像处理中如此常见。

1.3 奈奎斯特取样定理

定理内容：

    取样频率 fsfs​ 必须大于或等于信号最高频率 fmaxfmax​ 的2倍，即 fs≥2fmaxfs​≥2fmax​，才能从取样后的离散信号中无失真地恢复原信号。

在图像中的意义：

    图像也有“空间频率”。高频对应边缘、纹理等细节变化快的区域。

    如果采样频率不足（分辨率太低），就会出现摩尔纹或锯齿，高频细节丢失或产生假信号。

    例如：拍摄细密条纹布料时，如果传感器分辨率不够，就会出现奇怪的花纹，这就是违背了奈奎斯特定理。

工程应用：

    工业相机选型时，要保证像素精度高于最小缺陷尺寸对应的空间频率。

    手机拍照时，光学低通滤波器（OLPF）故意模糊掉超过奈奎斯特极限的高频，防止摩尔纹。

1.4 量化与采样的综合选择

这是一条非常重要的工程权衡原则：

        在灰度变化平缓的区域（如天空、皮肤），多用量化级（高位深），保证渐变平滑无“色带”；

        在灰度变化剧烈的区域（如边缘、文字），用高分辨率（密采样），保证轮廓清晰。

为什么不能无脑全用最高？

    数据量 = 分辨率 × 位深，两者同时提高，存储和传输压力会爆炸。

    实际工程中，要根据场景特性做取舍：

        医疗影像（CT/MRI）：通常高位深（10~12bit），但分辨率适中，因为病灶差异可能很细微。

        监控视频：高分辨率（如4K），但位深可以是8bit，因为重点在看清物体轮廓，色彩过渡要求不高。

工程中这一章有什么用？

很多人觉得“取样和量化”太基础，但实际工程中，大量图像质量问题都源于这两步没选对：

    车牌识别系统：摄像头分辨率不够（采样不足），导致小号牌字符粘连；或者光照太暗时量化噪声严重，灰度级不够区分字符与背景。

    手机夜景模式：通过多帧合成，等效提高量化信噪比，本质是在突破单帧量化的局限。

    工业缺陷检测：缺陷可能只有几个像素大小，如果采样分辨率不够，缺陷就被“平均”掉了。

1. 空间域 vs 频率域：两种“看图像”的方式
空间域（Spatial Domain）

    就是像素矩阵本身：(x, y) 坐标对应一个灰度值（或RGB值）。

    我们平时看到的图像就是空间域的表现。

    操作：对像素值直接修改（如对比度调整、平滑、锐化等）。

频率域（Frequency Domain）

    把图像看作由不同频率的正弦波叠加而成的。

    每一个频率分量代表图像中“变化快慢”的模式：

        低频：变化平缓的区域（如大块天空、皮肤、墙壁）。

        高频：变化剧烈的区域（如边缘、纹理、噪声点）。

    频率域里，每个点（u, v）代表一个特定频率和方向的波。

比喻：

    空间域 = 乐谱上的音符（每个时刻的响度）

    频率域 = 这首曲子的频谱（哪些音调被弹得多）

    一首曲子既可以写成乐谱（时域），也可以写成频谱（频域），两者描述的是同一声音，只是角度不同。

2. 滤波：在空间域和频率域“筛选信息”

滤波就是有选择地保留或去除图像中的某些成分。
空间域滤波

    用一个卷积核（模板）在图像上滑动，对每个像素的邻域做加权求和。

    例如：

        平滑滤波（均值、高斯）→ 抑制高频，模糊图像。

        锐化滤波（拉普拉斯、Sobel）→ 增强高频，突出边缘。

频率域滤波

    先把图像变换到频率域（傅里叶变换），得到一个频谱。

    然后用一个滤波器函数（如低通、高通）乘以频谱，再逆变换回空间域。

    本质上与空间域卷积等价（卷积定理：空间域的卷积 = 频率域的乘积）。

关键：两种滤波方式效果相同，但频率域更容易理解“哪些信息被保留或删除”。
3. 高频系数与低频系数

当我们对图像做傅里叶变换（或离散余弦变换 DCT）后，得到的变换系数中：

    低频系数：对应频谱中心（若已做中心化）附近的值。

        数值往往较大，因为图像的大部分能量集中于此。

        这些系数决定了图像的整体亮度和大块结构。

    高频系数：对应频谱外围的值。

        数值通常较小（除边缘、噪声外）。

        这些系数决定了图像的细节、纹理、边缘。

直觉：
拿掉所有高频系数，图像会变得模糊但轮廓仍在（只剩低频）。
拿掉所有低频系数，图像只剩下边缘和纹理，像一张“轮廓图”。
4. 高低频与能量的关系（着重）
4.1 什么是“能量”？

在图像处理中，能量通常指所有像素值的平方和（或变换系数的平方和）。
根据 Parseval 定理，空间域的能量 = 频率域的能量。
4.2 自然图像的能量分布

    绝大部分能量集中在低频区域。
    你可以想象：一张普通照片里，“大面积平缓的区域”占主导，边缘和噪声只占很小一部分。

    高频区域的能量通常很小。

4.3 为什么这很重要？

    压缩：既然高频能量很小，我们可以只保留少量低频系数，丢掉大部分高频系数，而视觉上损失不大（JPEG 的核心思想）。

    去噪：噪声通常在高频，所以低通滤波可以有效去噪。

    边缘提取：高通滤波可以突出高频，从而提取边缘。

    能量集中性：好的正交变换（如 DCT）能将能量压缩到少数系数中，便于编码和特征提取。

4.4 实验验证

你可以想象：对一张图像做傅里叶变换，将频谱中心化，然后计算以中心为圆心、半径为 R 的圆内能量占总能量的比例。你会发现，即使 R 很小（如半径仅为频谱尺寸的 10%），也能包含 90% 以上的总能量。这就是“能量集中”的直观表现。
5. 其他必须补充的基础知识
5.1 卷积定理

    空间域的卷积 = 频率域的逐点乘法（反之亦然）

    意义：我们可以选择最容易实现的域来设计滤波器。比如，要做一个复杂形状的滤波，在频率域只需要简单画一个掩膜。

5.2 为什么需要变换域？

    压缩：利用能量集中性，减少数据量。

    去噪：低通滤波去除高频噪声。

    特征提取：在频率域提取纹理、周期性模式更直观。

    图像复原：频域表达退化模型（如运动模糊）更简洁。

5.3 常见变换

    傅里叶变换：最基础，将图像分解为正弦/余弦波。

    离散余弦变换（DCT）：JPEG 核心，实变换，能量集中性更好。

    小波变换：多分辨率分析，适合渐进传输、边缘检测等。

5.4 采样与频率的关系（呼应第一章）

    图像的“最高频率”受限于采样率（奈奎斯特频率）。若图像中细节频率过高，采样时会产生混叠（如摩尔纹）。

    在频域中，混叠表现为高频成分折叠到低频区域。

import cv2
import numpy as np
import matplotlib.pyplot as plt

# 读取灰度图像
img = cv2.imread('your_image.jpg', cv2.IMREAD_GRAYSCALE)
img = cv2.resize(img, (512, 512))  # 方便处理

# 傅里叶变换
f = np.fft.fft2(img)
fshift = np.fft.fftshift(f)   # 将低频移到中心
magnitude_spectrum = 20 * np.log(1 + np.abs(fshift))

# 计算能量分布（以中心为圆心的累计能量）
rows, cols = img.shape
crow, ccol = rows // 2, cols // 2
y, x = np.ogrid[:rows, :cols]
mask = (x - ccol)**2 + (y - crow)**2
radius = np.sqrt(mask)

# 排序半径并计算每个半径内的能量
radius_flat = radius.ravel()
energy_flat = np.abs(fshift).ravel() ** 2
sorted_idx = np.argsort(radius_flat)
cum_energy = np.cumsum(energy_flat[sorted_idx])
total_energy = cum_energy[-1]

# 绘制能量累积曲线
plt.plot(radius_flat[sorted_idx], cum_energy / total_energy)
plt.xlabel('Radius (pixels)')
plt.ylabel('Cumulative Energy Ratio')
plt.title('Energy Concentration in Frequency Domain')
plt.grid()
plt.show()

# 观察低频和高频重建效果
# 低通滤波：只保留中心周围半径为30的区域
rows, cols = img.shape
crow, ccol = rows//2, cols//2
mask_lp = np.zeros((rows, cols), np.uint8)
mask_lp[crow-30:crow+30, ccol-30:ccol+30] = 1
fshift_lp = fshift * mask_lp
f_ishift_lp = np.fft.ifftshift(fshift_lp)
img_lp = np.abs(np.fft.ifft2(f_ishift_lp))

# 高通滤波：去除低频区域
mask_hp = 1 - mask_lp
fshift_hp = fshift * mask_hp
f_ishift_hp = np.fft.ifftshift(fshift_hp)
img_hp = np.abs(np.fft.ifft2(f_ishift_hp))

# 显示结果
plt.figure(figsize=(12,4))
plt.subplot(131), plt.imshow(img, cmap='gray'), plt.title('Original')
plt.subplot(132), plt.imshow(img_lp, cmap='gray'), plt.title('Low Frequency')
plt.subplot(133), plt.imshow(img_hp, cmap='gray'), plt.title('High Frequency')
plt.tight_layout()
plt.show()

    高通重建后，只剩下边缘、纹理和噪声，背景变暗。

    能量累积曲线会显示：半径很小的区域就能包含大部分能量。

一、公式到底要不要理解？

要，但不是死记硬背，而是理解公式“在表达什么物理含义”。

比如傅里叶变换公式：
F(u,v)=∑x=0M−1∑y=0N−1f(x,y)e−j2π(ux/M+vy/N)
F(u,v)=x=0∑M−1​y=0∑N−1​f(x,y)e−j2π(ux/M+vy/N)

如果你只记这个求和式子，确实很抽象。但如果你知道：

    e−j2π(⋅)e−j2π(⋅) 代表一个旋转的“正弦波探测器”

    整个公式的意思是：拿一个特定频率 (u,v)(u,v) 的正弦波，去和图像每一个像素相乘并累加。如果图像里这个频率的成分多，累加结果就大。

    那么你一下子就懂了：傅里叶变换本质上就是在计算图像和每个正弦波的相似度。

结论：你需要的是公式的“翻译版”，不是公式本身。你之前的“不明不白”，很可能是因为教材只给了公式，没给这个翻译。

import cv2
import numpy as np
import matplotlib.pyplot as plt

# ----------------------------------------------
# 1. 显示原图及其频谱（让你看看频率域长什么样）
# ----------------------------------------------
def show_spectrum(image_path):
    # 读图并转为灰度
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        print("图片路径错误，请检查")
        return
    
    # 傅里叶变换
    f = np.fft.fft2(img)               # 二维FFT
    fshift = np.fft.fftshift(f)        # 低频移到中心
    magnitude = np.log(1 + np.abs(fshift))  # 取幅度并压缩显示范围
    
    # 画图
    plt.figure(figsize=(10,5))
    plt.subplot(121), plt.imshow(img, cmap='gray'), plt.title('Original Image')
    plt.subplot(122), plt.imshow(magnitude, cmap='gray'), plt.title('Frequency Spectrum (center = low freq)')
    plt.show()

# ----------------------------------------------
# 2. 低通滤波实验：只保留中心低频，去掉高频
#    效果：图像模糊，但整体轮廓保留
# ----------------------------------------------
def lowpass_filter(image_path, radius=30):
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        print("图片路径错误")
        return
    
    # 傅里叶变换
    f = np.fft.fft2(img)
    fshift = np.fft.fftshift(f)
    
    # 生成低通掩膜：中心一个圆内为1，其余为0
    rows, cols = img.shape
    crow, ccol = rows//2, cols//2
    mask = np.zeros((rows, cols), np.uint8)
    cv2.circle(mask, (ccol, crow), radius, 1, -1)   # 白色圆形区域=低频保留
    
    # 应用掩膜（频域乘法）
    fshift_filtered = fshift * mask
    # 逆变换回空间域
    f_ishift = np.fft.ifftshift(fshift_filtered)
    img_filtered = np.abs(np.fft.ifft2(f_ishift))
    
    # 显示结果
    plt.figure(figsize=(12,4))
    plt.subplot(131), plt.imshow(img, cmap='gray'), plt.title('Original')
    plt.subplot(132), plt.imshow(mask, cmap='gray'), plt.title('Lowpass Mask (white=keep)')
    plt.subplot(133), plt.imshow(img_filtered, cmap='gray'), plt.title(f'Lowpass Result (radius={radius})')
    plt.show()

# ----------------------------------------------
# 3. 高通滤波实验：只保留高频，去掉中心低频部分
#    效果：只剩边缘、纹理、噪声
# ----------------------------------------------
def highpass_filter(image_path, radius=30):
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        print("图片路径错误")
        return
    
    f = np.fft.fft2(img)
    fshift = np.fft.fftshift(f)
    
    # 生成高通掩膜：中心圆内为0，其余为1（与低通相反）
    rows, cols = img.shape
    crow, ccol = rows//2, cols//2
    mask = np.ones((rows, cols), np.uint8)
    cv2.circle(mask, (ccol, crow), radius, 0, -1)   # 中心圆形区域设为0（去掉低频）
    
    fshift_filtered = fshift * mask
    f_ishift = np.fft.ifftshift(fshift_filtered)
    img_filtered = np.abs(np.fft.ifft2(f_ishift))
    
    # 显示
    plt.figure(figsize=(12,4))
    plt.subplot(131), plt.imshow(img, cmap='gray'), plt.title('Original')
    plt.subplot(132), plt.imshow(mask, cmap='gray'), plt.title('Highpass Mask (black=removed)')
    plt.subplot(133), plt.imshow(img_filtered, cmap='gray'), plt.title(f'Highpass Result (radius={radius})')
    plt.show()

# ----------------------------------------------
# 额外：能量集中展示（自动计算低频圆内能量占比）
# 不需要你改代码，直接运行会打印百分比
# ----------------------------------------------
def energy_concentration(image_path, radius=30):
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        print("图片路径错误")
        return
    
    f = np.fft.fft2(img)
    fshift = np.fft.fftshift(f)
    energy = np.abs(fshift) ** 2   # 每个频率分量的能量
    
    total_energy = np.sum(energy)
    
    # 计算半径为radius的圆内能量
    rows, cols = img.shape
    crow, ccol = rows//2, cols//2
    y, x = np.ogrid[:rows, :cols]
    mask_circle = (x - ccol)**2 + (y - crow)**2 <= radius**2
    energy_in_circle = np.sum(energy[mask_circle])
    
    percent = 100 * energy_in_circle / total_energy
    print(f"半径为 {radius} 像素的低频圆内包含的能量占总能量的比例: {percent:.2f}%")
    
    # 显示低频频谱区域（白色部分）
    plt.imshow(mask_circle, cmap='gray')
    plt.title(f"Low-frequency region (radius={radius})")
    plt.show()

第三章 图像增强

图像增强的目标很简单：让图像更适合人眼看，或者更适合后续机器处理。它不增加图像的信息量，只是把某些信息突显出来，同时压制不重要的部分。

主要包括两大类：

    空域增强（直接操作像素）

        灰度变换（对比度拉伸、直方图均衡化）

        平滑去噪（均值滤波、高斯滤波、中值滤波）

        锐化（边缘突出，如拉普拉斯、Sobel）

    频域增强（我们已有基础，本章只提概念，代码里可选）

3.1 灰度变换 —— 最简单的对比度调整
基本概念

原图像可能偏暗、偏亮、或者对比度太低（灰度挤在一起）。
灰度变换就是对每个像素的灰度值 r，用一个函数 s = T(r) 映射到新的灰度 s。
简单公式（分段线性变换）

想把原图灰度范围 [a, b] 拉伸到 [c, d]：
s=c+d−cb−a×(r−a)
s=c+b−ad−c​×(r−a)

    如果 r<a 则缩到更暗，r>b 则压缩到更亮，中间部分拉伸。

    效果：中间对比度增强。

实际场景

    医学X光片：原始图像灰度范围窄，拉伸后能看清软组织与骨骼的边界。

    夜间监控：整体偏暗，用线性变换提高亮度。

    雾天图像：先直方图均衡化（见下）再去雾。

3.2 直方图均衡化 —— 自动对比度增强
概念

直方图是各灰度级像素个数的统计。
如果图像的灰度级集中在某一段，图像看起来灰蒙蒙的。
均衡化就是把原图的灰度分布重新映射，让结果图像的直方图近似均匀分布，从而自动拉开对比度。
简单步骤（不用背公式，理解过程）

    统计原图每个灰度 k 的像素个数 n_k

    计算累积分布函数 CDF(k) = 灰度 ≤ k 的像素比例

    新灰度 = round( CDF(k) × 255 )

    将原图中所有灰度 k 替换为新灰度。

直观理解：像素多的灰度级被拉伸得更开，像素少的被压缩。结果图像细节更清晰。
实际场景

    人脸识别预处理：不同光照下拍的图片，均衡化后光照影响减小。

    水下摄影：绿色/蓝色偏重，均衡化能恢复部分颜色对比。

    手机拍照的“自动增强”：很多算法第一步就是自适应直方图均衡化（CLAHE）。

3.3 图像平滑（去噪） —— 让图像干净
概念

噪声是图像中随机的亮度变化（比如摄像头高ISO产生的颗粒）。平滑就是抑制这些变化。

均值滤波
用一个 k×k 小窗口（模板），窗口内所有像素取平均值作为中心点的新值。
公式：
g(x,y)=1k2∑i=−ww∑j=−wwf(x+i,y+j)
g(x,y)=k21​i=−w∑w​j=−w∑w​f(x+i,y+j)

效果：噪声被平均掉，但边缘也变模糊。

高斯滤波
均值滤波的改进版：中心点的权重最高，离中心越远权重越小。能更好地保留边缘。
核值由高斯函数决定。

中值滤波
取窗口内所有像素的中位数代替中心点。
对椒盐噪声（黑白斑点）效果极好，且保留边缘比均值滤波好得多。
实际场景

    工业质检：去除金属表面的细粒噪声，却要保护划痕边缘不被模糊。

    老照片修复：扫描照片有颗粒感，先用中值滤波。

    视频监控：低光照下噪声严重，使用高斯滤波后再做人脸检测。

3.4 图像锐化 —— 让边缘更清晰
概念

锐化是为了突出图像的边缘和细节。
边缘处灰度变化剧烈，所以锐化本质上就是增强图像的高频成分。

拉普拉斯算子（二阶导数）
模板例子：
[0−10−14−10−10]
​0−10​−14−1​0−10​
​

应用方法：原图 + 拉普拉斯滤波结果（系数可调）。

Sobel算子（一阶导数）
两个模板分别检测水平边缘和垂直边缘，然后合成梯度幅值。

直观理解：锐化就像是把图像的“轮廓线”描黑一点。
实际场景

    印刷品/文档扫描：让文字边缘更清晰，便于OCR。

    卫星图像：增强建筑物、道路的轮廓。

    医学CT：让器官边界更明显，辅助医生诊断。

3.5 彩色增强（简述）

    可以在RGB三个通道分别做灰度增强，但容易色偏。

    常用做法：转换到HSV空间，只对亮度（V）通道做增强，保持色相（H）和饱和度（S）不变。

    场景：照片调色、视频滤镜。

import cv2
import numpy as np
import matplotlib.pyplot as plt

# ==============================================
# 辅助函数：显示原图和处理结果
# ==============================================
def show_images(original, processed, title1="Original", title2="Processed"):
    plt.figure(figsize=(10,5))
    plt.subplot(121), plt.imshow(original, cmap='gray'), plt.title(title1)
    plt.subplot(122), plt.imshow(processed, cmap='gray'), plt.title(title2)
    plt.show()

# ==============================================
# 1. 灰度线性变换（对比度拉伸）
# 公式：s = c + (d-c)/(b-a) * (r - a)
# 作用：将原图灰度范围 [a,b] 拉伸到 [c,d]，增强中间区域对比度
# ==============================================
def linear_stretch(image, a, b, c, d):
    """
    image: 灰度图 (0-255)
    a, b: 原图中要拉伸的灰度范围（通常是 min, max 或者自定义）
    c, d: 目标灰度范围
    """
    # 确保图像是 float 类型，避免溢出
    img_float = image.astype(np.float32)
    # 线性映射
    stretched = c + (d - c) / (b - a) * (img_float - a)
    # 裁剪到 [0,255] 并转成 uint8
    stretched = np.clip(stretched, 0, 255).astype(np.uint8)
    return stretched

# ==============================================
# 2. 直方图均衡化（自动增强对比度）
# 原理：重新映射灰度，使输出直方图近似均匀分布
# 作用：对光照不均、整体偏暗或偏亮的图效果明显
# ==============================================
def histogram_equalize(image):
    # OpenCV 提供的直方图均衡化（自动处理）
    return cv2.equalizeHist(image)

# ==============================================
# 以下三个函数用于去噪演示，调用前需要先施加椒盐噪声
# ==============================================

# 椒盐噪声攻击函数
def salt_pepper_noise(image, prob=0.02):
    """
    添加椒盐噪声
    prob: 噪声比例（每个像素被替换为椒或盐的概率）
    """
    output = image.copy()
    # 椒盐噪声：随机将一些像素设成 0（胡椒）或 255（盐）
    rand = np.random.rand(*image.shape)
    output[rand < prob/2] = 0
    output[rand > 1 - prob/2] = 255
    return output

# 3. 均值滤波（平滑去噪）
def mean_filter(image, ksize=3):
    """
    均值滤波：用窗口内所有像素的平均值替代中心像素。
    优点：简单、快速；缺点：模糊边缘。
    适用：高斯噪声、轻度颗粒噪声。
    """
    return cv2.blur(image, (ksize, ksize))

# 4. 中值滤波（保护边缘的去噪）
def median_filter(image, ksize=3):
    """
    中值滤波：用窗口内所有像素的中位数替代中心像素。
    优点：对椒盐噪声效果极好，且几乎不模糊边缘。
    缺点：对高斯噪声效果不如均值滤波。
    """
    return cv2.medianBlur(image, ksize)

# 5. 高斯滤波（保留边缘的平滑）
def gaussian_filter(image, ksize=3, sigma=0):
    """
    高斯滤波：根据高斯函数给邻域像素加权平均，中心权重大，边缘权重小。
    优点：平滑噪声的同时，比均值滤波更保留边缘。
    适用：高斯噪声（常见于低光照图像）。
    """
    return cv2.GaussianBlur(image, (ksize, ksize), sigma)

二、核心区别讲解（重要）
1. 灰度线性变换 vs 直方图均衡化
维度	灰度线性变换	直方图均衡化
原理	对灰度范围进行线性映射（可手动设定输入输出范围）	根据累积分布函数重新分配灰度，使输出直方图尽量均匀
是否自适应	否，需要人工指定 (a,b,c,d)	是，自动根据图像灰度分布计算映射
控制能力	可精确控制哪些灰度级被拉伸或压缩	无法精确控制，结果是固定的均匀化
典型效果	对比度可控，但可能把噪声也拉伸	整体对比度提升，但可能放大噪声
场景	已知目标灰度范围的场合（如医疗图像标准化）	光照不均、整体偏暗/偏亮的照片自动增强

一句话总结：线性变换是“手动挡”，直方图均衡化是“自动挡”。
2. 均值滤波 vs 中值滤波 vs 高斯滤波
维度	均值滤波	中值滤波	高斯滤波
运算	取窗口内像素的算术平均	取窗口内像素的中位数	加权平均，权重由高斯函数决定
对椒盐噪声效果	差（噪声值会拉偏平均值）	极好（中位能有效排除极端值）	一般（噪声仍会影响平均值）
对高斯噪声效果	较好	一般（不如均值）	最好（因为高斯噪声符合正态分布，高斯滤波是最优线性滤波器）
边缘保留能力	差，边缘会明显模糊	好（边缘处中位数仍保持原边缘值）	中等，略好于均值但不如中值
计算速度	快	慢（需要排序）	快（可分离卷积）
典型场景	旧代码、实时性要求极高的场合	椒盐噪声、扫描文档去斑点	低光照照片去噪、手机夜景算法

更加直观的实验建议：
